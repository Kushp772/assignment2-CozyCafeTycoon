# Cozy Café Tycoon – Assignment 2

## Overview
This project is part of Assignment 2. It includes data modeling and Swift exercises based on a café simulation game concept.

## Part A – Data Models
The Models folder contains:
- Recipe.swift → primary data model
- RecipeCategory.swift → enum for recipe types
- GameState.swift → enum with associated values
- SampleData.swift → test data for recipes

## Part B – Swift Exercises
The playground file includes:
- Error handling (throw, do-catch, try?, try!)
- Protocols and conformance
- Generics
- Type casting
